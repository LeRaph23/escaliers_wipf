# memoire-clones

Prototypes clean-room pour une étude sur la reproductibilité d'applications par IA. Voir [ANALYSE.md](ANALYSE.md).

- `lumen-ios/` : navigateur vidéo + bloqueur de pub (SwiftUI, à compiler sous Xcode)
- `cadence-pwa/` : lecteur musical PWA (lecteur YouTube officiel). Lancer : `python3 -m http.server -d cadence-pwa 8080`, puis ouvrir http://localhost:8080
